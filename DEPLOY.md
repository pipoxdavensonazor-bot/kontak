# Déploiement gratuit sur Render

## Étapes (5 minutes)

1. Va sur https://render.com et crée un compte (gratuit, pas de carte)
2. Clique sur **New +** → **Web Service**
3. Connecte GitHub et choisis le repo `kontak`
4. Paramètres :
   - Build Command : `npm install`
   - Start Command : `npm start`
   - Instance Type : **Free**
5. Clique **Create Web Service**

L’URL sera du type : `https://kontak-xxxx.onrender.com`

## TURN gratuit (Open Relay)

1. Va sur https://www.metered.ca/tools/openrelay/
2. Crée un compte gratuit
3. Copie l’URL TURN, username et password
4. Dans l’app, clique sur le bouton **TURN** et colle les infos
